# Customer Success Portfolio: Umekulume Chinwendu Maryann

A responsive static portfolio built with HTML, CSS and JavaScript. No framework or build step is required.

## Included
- `index.html` – portfolio content and structure
- `style.css` – dark navy and blue visual design
- `script.js` – mobile navigation and scroll-reveal behaviour
- `assets/case-studies/` – the three original case-study PDFs linked from the website

## Preview locally
Open `index.html` in a browser. The case-study PDF links work from the local folder structure as well as after deployment.

## Publish when ready
Upload the contents of this ZIP to the root of your GitHub repository. If you later connect the repository to Netlify, use the repository root as the publish directory and leave the build command empty. Nothing in this package has been published automatically.
